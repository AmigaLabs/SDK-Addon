# SDK-Addon
This repository hosts the releases of the AmigaOS 4 SDK Addon package

The SDK Addon package is meant to be installed on top of the AmigaOS 4 SDK. This includes new versions of necessary tools and compilers for native development on AmigaOS 4 systems. The package contains an installer that helps the user to proceed with the installation with just a few clicks.

This package contains native versions of:

- gcc13
- gcc11
- gcc8
- gcc6
- clib4

We are working to add more tools in the future releases, that will help the developers to have a better experience for native development on AmigaOS 4. This package might include experimental software. If you experience any problems, feel free to open an issue, so that we can work on a fix.

Happy coding.
